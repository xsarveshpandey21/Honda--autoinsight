# 🚗 Honda AutoInsight — Automotive Analytics Dashboard

**Honda AutoInsight** is an interactive, high-performance automotive intelligence platform built with **React 19**, **TypeScript**, **Tailwind CSS v4**, **Recharts**, and **Vite**.

It allows users to visualize sales trends, analyze vehicle models, clean automotive datasets, compare specifications, and generate executive reports.

---

## ✨ Features

- 📊 **Overview Analytics**: Real-time sales volume, revenue metrics, and market share breakdown.
- 📈 **Sales & Market Trends**: Detailed price-vs-mileage distribution and multi-year sales velocity charts.
- 🏎️ **Vehicle Catalogue**: Interactive car cards, search, dynamic filtering, and detailed spec inspect modal.
- ⚖️ **Side-by-Side Comparison**: Compare multiple Honda models on price, horsepower, fuel efficiency, and safety ratings.
- 📋 **Data Quality Engine**: Automated dataset sanitization, missing value detection, and anomaly resolution.
- 📄 **Executive Reports**: Generate summary insights and export dashboard visuals.

---

## 🛠️ Built With

- **Framework**: React 19 + TypeScript
- **Styling**: Tailwind CSS v4 + Lucide Icons
- **State Management**: Zustand
- **Data Visualization**: Recharts + Virtualization (@tanstack/react-virtual)
- **Data Processing**: PapaParse
- **Build Tool**: Vite 8

## 🚀 Quick Start (Local Setup)

```bash
# Clone the repository
git clone https://github.com/YOUR-USERNAME/honda-autoinsight.git

# Navigate to project directory
cd honda-autoinsight

# Install dependencies
npm install

# Start development server
npm run dev
```
